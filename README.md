## 분석에서 정한 선택

1. **레이블:** B1 46셀 중 종료에서 멀리 끝난 10셀을 제외하고 종료 근접 36셀을 학습 후보로 삼는다. 이 36개도 실제 EOL을 관측한 정확한 정답은 아니다.
2. **초기 신호:** 용량 기울기는 기록 중단과 구간 선택에 민감해 주 입력에서 보류한다. `log10 var(ΔQ)`는 후보로 유지하되, 정책만 쓴 모델에 더했을 때의 검증 이득을 확인한다.
3. **모델:** 소표본·입력 중복을 고려해 Ridge를 우선한다. Elastic Net으로 변수 선택의 이득을 비교하고, 검증 잔차에 비선형 패턴이 반복될 때만 얕은 회귀트리를 비교한다. 첫 입력 구성은 ΔQ 1개 / 정책 3개 / 결합 4개다. QD·IR·온도·충전 시간 추가는 이번 주 비교에서 보류한다.
4. **검증:** 정책 단위로 학습 28셀·홀드아웃 8셀을 고정했다. 모델 선택 후 **같은 28셀 학습 모델**로 홀드아웃과 B2를 평가한다. B2용으로 36셀에 재학습하지 않는다.
5. **적용 범위:** B2에는 학습 입력 범위를 벗어나는 셀이 많다. 표기별·입력 범위 안팎의 오차를 구분한다.

## Q2. 열화 곡선 - 방전 용량이 어떻게 감소하는가? — PDF 8~9쪽

종료 근접 B1 36셀/B2 39셀/B3 44셀은 후반 용량 감소 가속을 보였다. 같은 분석 대상의 탐색 knee 중앙값은 579/361/827사이클이다. 전체 경로로 구한 knee는 입력에서 제외한다. PDF의 진한 선과 knee 표시는 수명 순서의 대표 셀이며 집단의 knee 중앙값과 다르다.

B2 레이블 39셀 모두 초기 20~100사이클 안에 약 65.4시간의 기록 간격이 있었다. standard의 공백 사이클은 46~53, newstructure는 68~77이므로 20~40과 80~100을 공통 전후 구간으로 비교했다.

| B2 집단 | 20~100 전체 | 20~40 공백 전 | 80~100 공백 후 |
|---|---:|---:|---:|
| standard 30셀 | -4.0 | -7.0 | -3.6 |
| newstructure 9셀 | +3.8 | +1.2 | -6.3 |

값은 셀별 Theil-Sen **용량 감소 기울기 중앙값**, mAh/100사이클 환산이다. 음수는 용량 증가다. 짧은 구간의 환산값이며 실제 100사이클 동안의 손실량은 아니다. 구간을 바꾸면 newstructure의 방향이 반전되어 이를 영구적인 열화 속도로 해석하기 어렵다. 장비 중단과 용량 변화의 인과관계는 로그 없이 확정하지 못한다.

ΔQ 분산도 구간에 민감했다. B2에서 수명과의 상관은 10→100 -0.71, 공백 전 10→40 -0.38, 공백 후 80→100 -0.64다. 구간 길이도 달라 직접 효과 비교는 아니며, 공백 영향 제거를 입증한 결과는 아니다. **용량 기울기는 주 입력에서 보류한다. ΔQ의 구간 안정성과 정책에 더하는 예측 정보는 별도 질문으로 해석한다.**

## Feature Engineering — PDF 22~23쪽

첫 비교를 **ΔQ 1개 / 정책 3개 / 결합 4개**로 제한한다.

- **ΔQ 1개:** `log10 var(ΔQ)`로 전압별 변화 폭을 요약한다. 평균·최솟값은 중복이 커 함께 넣지 않는다. B2의 10→100 / 10→40 / 80→100 구간에서 수명 상관은 -0.71 / -0.38 / -0.64로, 강도는 달라도 방향은 같다. 이를 후보 유지의 근거로 삼고 정책 대비 추가 예측력으로 채택을 판단한다.
- **정책 3개:** 첫 C-rate, 둘째 C-rate, 전환 SOC. 충전 조건을 함께 반영해 ΔQ가 더하는 정보를 비교한다.
- **용량 기울기·고전류 비율 보류:** 구간 또는 배치가 바뀌면 관계가 달라진다.
- **QD·IR·온도·충전 시간 보류:** 추가 예측 정보는 미확정이다. 소표본에서 첫 비교의 수를 제한하며, 이 변수들이 무용하다고 결론 내린 것은 아니다.

ΔQ 분산의 왜도는 로그 변환 전 +1.11, 후 +0.22다. 같은 36셀의 원래 수명을 세로축에 두어 **입력 변환**만 비교했다. 로그 변환이 성능을 보장하거나 Ridge가 입력 정규성을 요구한다는 뜻은 아니다.

## Regression vs Classification · 타깃 선택 — PDF 25쪽

수명을 연속값으로 예측해 셀별 점검 우선순위를 비교하려고 **회귀**를 선택한다. 분류 기준 550사이클 미만은 B1 전체에서 1셀뿐이라 분류 경계를 학습하기도 어렵다. 입력은 100사이클까지의 기록, 타깃은 저장 `cycle_life`의 **총 사이클 수**다. B1은 정확한 EOL 관측이 아닌 종료 근사값이라는 한계가 남는다.

수명 자체의 왜도는 B1 종료 근접 36셀에서 +0.30으로 심하지 않다. 원래 수명과 로그 수명을 같은 CV에서 비교하고, 원 단위로 복원한 예측의 MAPE로 선택한다. 로그 제곱오차와 MAPE는 동일하지 않으며, 입력 변환의 근거를 타깃 변환의 근거로 사용하지 않는다.

`GroupShuffleSplit(test_size=0.2, random_state=20261001)`로 B1 후보 36셀·20정책을 고정했다.

| 구분 | 셀/정책 | 수명 중앙값 | 수명 범위 |
|---|---:|---:|---:|
| 학습 | 28/16 | 848 | 599~1,074 |
| 홀드아웃 | 8/4 | 676.5 | 534~870 |

홀드아웃은 새 정책이면서 더 짧은 수명에 치우친 평가다. 이 특성을 공개하며 유리한 점수를 얻기 위해 재분할하지 않는다. 학습 풀의 4-fold GroupKFold는 매 폴드 21셀 학습/7셀 검증이다. 전처리는 폴드 학습 자료에서만 추정한다. 모델 선택 후 같은 28셀 학습 모델을 홀드아웃·B2에 적용하고, 홀드아웃 결과로 재튜닝하지 않는다.

## DAY 2 모델·평가 계획 — PDF 27~31쪽

### EDA 근거에서 후보 모델로

| 후보·역할 | EDA에서 확인한 특성 | 선택 이유와 검증 질문 |
|---|---|---|
| **Ridge · 우선 후보** | 실제 학습 28셀, CV 학습 21셀. B1 후보 36셀에서 첫 C-rate와 전환 SOC의 상관 -0.88 | 계수 크기를 제약해 작은 표본과 입력 중복에 대응한다. ΔQ / 정책 / 결합을 비교해 어떤 입력 구성이 새 정책에서도 유효한지 확인한다. |
| **Elastic Net · 보조 후보** | ΔQ와 수명의 상관이 같은 32셀에서 전체 -0.82 → 정책 평균 제거 후 -0.11로 약해짐 | 일부 입력을 제외하는 것이 Ridge보다 유리한지 비교한다. 이 관찰만으로 불필요한 변수를 확정하지 않고, 정책 3개·결합 4개에서 오차와 선택 변수의 일관성을 확인한다. |
| **얕은 회귀트리 · 조건부 후보** | 입력 로그 변환으로 왜도는 +1.11→+0.22로 줄지만, 관계의 선형성까지 입증되지는 않음 | 선형 모델의 검증 잔차에 곡률·조건별 패턴이 반복되면 단순 분기와 상호작용을 비교한다. 깊이 2·리프 최소 5셀로 복잡도를 제한한다. |

Ridge의 L2 제약과 Elastic Net의 L1·L2 결합은 [scikit-learn 선형 모델 문서](https://scikit-learn.org/stable/modules/linear_model.html)에 따른다. 회귀트리는 학습한 구간의 상수 예측을 조합하므로 학습 범위 밖 추세를 이어가는 데 한계가 있다. B2의 입력 범위 이탈을 트리 도입의 근거로 삼지 않는다. [회귀트리 문서](https://scikit-learn.org/stable/modules/tree.html)

### 비교 순서와 고정 조건

1. **기준선:** 각 학습 폴드 레이블의 `1/y` 가중 중앙값. MAPE의 상수 예측 기준으로 사용한다.
2. **Ridge:** ΔQ만 / 정책만 / 결합, α={0.1, 1, 10, 100}, 원래 수명 / 로그 수명을 비교한다. 먼저 입력 구성의 추가 이득과 정규화 강도를 확인한다.
3. **Elastic Net:** 정책 3개 / 결합 4개에서 α={0.01, 0.1, 1}, L1 비중={0.2, 0.8}, 원래 수명 / 로그 수명을 비교한다. 폴드마다 남는 변수와 계수 부호도 기록한다. 단일 ΔQ 입력에서는 변수 선택 질문이 없어 이 비교를 생략한다.
4. **얕은 회귀트리:** 선형 모델의 폴드 외 예측 잔차에 비선형 패턴이 반복될 때만 비교한다. 선택된 선형 모델과 같은 입력 구성·타깃 변환을 사용해 모델 형태의 차이를 확인한다. 깊이 2, 최소 리프 5셀을 고정한다.

모든 후보는 **같은 정책 그룹 4-fold CV와 원 단위 MAPE**로 비교한다. 선형 모델의 입력과 변환 후 타깃을 표준화하며, 대치값·평균·표준편차는 학습 폴드에서만 추정한다. 타깃은 표준화를 되돌리고, 로그 수명은 지수 변환까지 거친 뒤 평가한다. 위 α 범위는 이 스케일을 전제로 한다.

**채택 규칙:** Elastic Net은 최선의 Ridge, 트리는 최선의 선형 후보보다 평균 MAPE가 1%p 이상 낮고 4개 중 3개 폴드에서 개선될 때 채택한다. Ridge의 입력 추가도 같은 규칙으로 판단한다. 1%p는 사전 선택 규칙이며 통계적 유의성 기준은 아니다. 차이가 작으면 기존 후보와 더 적은 입력을 유지한다. 기준선도 넘지 못하면 모델 채택을 보류한다. 비교는 B1 CV에서 마치고 홀드아웃·B2 결과로 후보나 설정을 다시 고르지 않는다.

| 과제 보고 항목 | 계획 |
|---|---|
| Train (B1 CV) | 검증 폴드 MAPE 평균·폴드별 값 |
| Valid (B1 Hold-out) | 8셀 MAPE·MAE·오차 방향 |
| Test (B2) | 전체 및 표기별·각 모델이 사용하는 입력의 범위 안팎 |
| Gap (Train-Valid) | Valid - CV |
| Gap (Valid-Test) | Test - Valid |
| Gap (Target-Test) | Test - 9.1 |

Gap 단위는 %p, 양수는 오차 증가다. 과대 예측률과 평균 상대 오차도 보고한다. CV는 모델 선택에도 사용되어 선택 낙관편향이 남는다. 과제 EDA에서 B1 전체·B2·B3 레이블을 보았으므로 탐색 이후의 외부 진단으로 해석한다. 논문의 파일·연속 기록·분할이 과제와 달라 9.1%를 동일 조건 재현값으로 취급하지 않는다.

## 원시 기록 검증과 남은 범위

- B2 IR10·IR100의 0값 6셀은 결측으로 처리했다. 상관의 유효 표본은 33셀이다.
- 원시 방전 Qd에 누적 이후 간헐적 0값이 나오는 B2 6셀을 발견했다. 원시 곡선 재구성에서 해당 샘플만 제외했다. 셀 자체나 제공 Qdlin을 임의 삭제하지 않았다.
- 10·100번 사이클의 원시 방전 `V,Qd`를 **공통 내부 구간 2.05~3.45 V**에서 보간하고 시작값을 맞춰 제공 Qdlin과 비교했다. 형태 차이 RMSE 중앙값은 B1 0.42/B2 0.50/B3 0.46 mAh, 최대는 0.97/2.20/1.07 mAh였다.
- 재구성 ΔQ와 제공 ΔQ 분산의 셀별 순위 상관은 각 배치 0.997 이상이었다. 단순 수직 이동 불변성보다 강한 수치적 대응 확인이지만, 끝단 전압 구간이나 실험 조건의 동등성까지 검증한 것은 아니다.
- B3 원저자 제외 순서를 적용하면 레이블 보유 44셀에서 c37·c02·c42·c43 제외 후 40셀, ΔQ 수명 상관은 -0.80→-0.76이다. 평가 성능에 맞춘 사후 제거는 하지 않는다.
