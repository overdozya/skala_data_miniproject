## 핵심 판단

초기 전압별 용량 변화 `ΔQ(V)`는 유력한 후보지만, 그 상관을 셀 고유의 수명 신호로 확정할 수 없다. Batch 1의 `log10 var(ΔQ)`와 수명 상관은 전체 **-0.87**, 같은 정책의 평균을 제거하면 **-0.15**다. 따라서 DAY 2의 질문은 **“ΔQ가 정책만 사용한 모델에 추가 정보를 주는가?”**다.

그 전에 레이블부터 구분했다. B1의 46개 `cycle_life`는 모두 기록 길이+1이며, 실제 0.88 Ah 교차를 관측한 정답이 아니다. 종료에서 멀리 끝난 10셀을 주 학습에서 제외하고, **종료 근접 36셀의 저장 레이블을 종료 근사값으로 사용하는 회귀**를 설계했다. 이것도 정확한 EOL 예측의 입증은 아니다.

1순위는 **log 수명 Ridge**다. `log10 var(ΔQ)` 1개와 첫·둘째 C-rate, 전환 SOC 3개를 후보 입력으로 두고 `ΔQ만 / 정책만 / 결합`을 같은 정책 그룹 CV에서 비교한다. 복잡한 모델이나 변수를 추가할 조건을 먼저 정했다.

## 먼저 해결한 타깃 문제 — PDF 5쪽

| 레이블 검증 | B1 | B2 | B3 |
|---|---:|---:|---:|
| 실제 첫 QD <0.88 교차와 일치 | 0/46 | 39/39 | 0/44 |
| 레이블 = 기록 길이+1 | 46/46 | 0/39 | 44/44 |
| 마지막 QD ≤0.885 Ah | 36/46 | 39/39 | 44/44 |

- **주 학습:** B1 마지막 QD≤0.885인 36셀의 저장된 `cycle_life`. 종료 근사 레이블이며 실제 EOL 관측값이라고 하지 않는다.
- **제외:** B1 10셀은 마지막 QD가 0.913~1.043 Ah다. 종료 전 중단 가능성이 있어 주 회귀의 정답으로 쓰지 않는다.
- **대가:** 선택 후 수명 중앙값 858.5→772.5, 상한 1,227→1,074. 저속 충전·장수명 표본이 줄어든 선택 편향이 남는다.
- **민감도:** B1 46셀 분석은 별도 진단만 한다. 더 좋은 점수가 나왔다는 이유로 주 학습으로 바꾸지 않는다.
- **해결 경로:** 2017-06-30의 연속 기록을 확보해 해당 셀들의 레이블을 복원·검증한 뒤 설계를 다시 고정한다. 현재 그 파일은 없다. Huber 같은 회귀 손실 변경이 검열 레이블을 바로잡지는 않는다.

0.88 Ah가 기준이고 0.885 Ah는 원저자 코드에도 등장하는 종료 근접 점검선이다. 이 기준에 가깝다고 관측하지 않은 임계 교차가 자동으로 확인되는 것은 아니다. 종료 상태는 데이터 정제에만 쓰고 입력으로 넣지 않는다.

## Q2. 초기 변화와 후반 열화를 구분했는가? — PDF 7~9쪽

세 배치 모두 전체 경로에서 후반 감소 가속이 보인다. 탐색 knee는 45/46, 39/39, 44/44에서 검출됐고, 검출 셀의 시점 중앙값은 **631 / 361 / 827사이클**이다. 수명 대비 비율의 중앙값은 **76% / 79% / 81%**다. 거의 모든 셀에 있는 검출 여부는 구분력이 작고, 미래 곡선이 필요하므로 입력에서 제외한다. 단순 두 직선 탐색 결과이지 물리적 knee의 확정 판정은 아니다.

초기 QD 급변을 원시 `t`까지 추적하니 **B2 레이블 39셀 모두 20~100사이클 안에 약 65.4시간의 기록 간격**이 있었다. 실제 휴지인지 수집 누락인지는 모른다. B1은 1/46, B3는 0/44다. 강건 기울기를 써도 중단·재개로 생긴 변화까지 사라지는 것은 아니다.

`QD100-QD10`의 수명 상관은 **+0.61 / -0.05 / +0.03**이다. B2 standard는 초기 QD가 오히려 증가했지만 수명은 더 짧았다. 초기 용량 변화량을 비가역적 열화 속도라고 단정하지 않는다.

**모델 연결:** QD 변화량은 단독 주 피처로 채택하지 않고 비교 후보로 둔다. 전압별 초기 변화 형태인 ΔQ로 탐색을 확장한다.

## Q3. ΔQ는 정책·집단을 넘어서는 신호인가? — PDF 10~12쪽

`ΔQ(V)=Q100(V)-Q10(V)`를 물리적 10·100번 사이클에서 계산했다. 동일한 3.5→2.0 V, 1,000점 격자를 확인했다. 배치별 수명 하위 1/3에서 약 2.8~3.1 V의 음의 변화가 더 크다. 이 집단은 **분포 설명용**이며 Q1의 <500/>1,000 정의와 다르다.

| log10 var(ΔQ) ↔ 수명, Spearman ρ | B1 | B2 | B3 |
|---|---:|---:|---:|
| 전체 레이블 | -0.87 | -0.71 | -0.80 |
| 정책 평균 제거 후 | -0.15 | -0.33 | -0.47 |

정책 내부 비교는 1셀 정책을 제외했다. B1 45셀·22정책, 주 학습 후보에서는 32셀·16정책이다. 주 학습 36셀의 전체 상관은 -0.83이지만 내부 상관은 -0.11, 정책 재표집 95% 구간은 **-0.59~+0.38**다.

B2도 standard 내부 -0.38(n=30), newstructure 내부 -0.17(n=9)로 약해진다. 집단 안에서 상·하위 수명의 ΔQ 곡선을 다시 비교하면 겹침이 커진다. 표본 수와 수명 범위가 줄어든 영향도 있어 “정책이 전부 설명한다”는 증명은 아니다.

**모델 연결:** ΔQ 분산 한 개를 후보로 두고, 정책만 사용한 모델에 추가했을 때의 검증 이득을 확인한다. 전체 상관만으로 채택을 확정하지 않는다.

## Q4. 충전 패턴은 초기 변화와 수명에 어떻게 연결되는가? — PDF 13~14·22~23쪽

[전체 정책별 평균·표본 수·관측 범위](results/final/tables/all_policy_means.csv)를 비교했다. 첫 C-rate와 수명의 상관은 -0.48/+0.06/-0.23, 강건 초기 QD 감소 기울기와는 +0.38/+0.04/+0.14다. ΔQ 분산과는 +0.54/-0.03/+0.29다. 배치 전체에 일관된 단조 관계가 아니다.

실제 10번 사이클 `I(t)`도 열었다. 첫 방전 전 유효 충전 시간 중 **저장 I>4.2인 시간 비율**과 수명의 상관은 **-0.29/+0.05/+0.40**, 초기 QD 감소와는 **+0.16/-0.05/-0.04**다. 전환 SOC와 초기 QD 감소는 **-0.09/+0.01/-0.45**다. [전체 관계 표](results/final/tables/charging_associations.csv)에 둘째 전류와 ΔQ 관계도 포함했다.

저장 I의 평탄부는 정책 C-rate 값과 일치하고, 시간 적분/Qc 비는 배치 중앙값 약 0.91~0.92다. **C-rate 스케일로 추정**했으며, 단위 문서로 확정하지 못한 I를 A라고 표시하거나 다시 1.1로 나누지 않았다. 시간 비율은 이 저장 스케일의 진단값이다.

**모델 연결:** 첫 전류만으로 인과적 열화 법칙을 주장하지 않는다. 첫·둘째 C-rate와 SOC를 함께 비교하되, 실제 시간 비율은 이번 주 모델에 추가하지 않는다.

## DAY 2 모델과 평가 계획 — PDF 18~21쪽

1. **기준선:** 학습 레이블의 `1/y` 가중 중앙값. MAPE를 최소화하는 상수 예측과 비교한다.
2. **주 후보:** log 수명 Ridge, `α={0.1,1,10,100}`. B1 36셀의 수명 왜도는 raw +0.30, log -0.01로 원분포도 심한 왜곡은 아니다. raw 타깃 Ridge를 함께 비교한다. 로그 제곱오차와 MAPE가 같지는 않으므로 exp로 복원한 원래 수명의 MAPE로 선택한다.
3. **입력 비교:** ΔQ만 / 정책만 / 결합. 추가 변수는 하나씩 시험한다. 평균 MAPE와 4개 폴드 중 3개 이상에서 개선되는지 보고, 차이가 불확실하면 단순한 입력을 유지한다. 기준선보다 낫지 않으면 예측 가능성이 입증됐다고 주장하지 않는다.
4. **조건부 보조 후보:** B1 검증 잔차에서 반복되는 비선형이 남을 때만 깊이 2~3 트리를 비교한다. Huber는 미관측 수명의 해법으로 사용하지 않는다.

**고정 분할:** `GroupShuffleSplit(test_size=0.2, random_state=20261001)`로 B1 36셀·20정책 중 **학습 28셀·16정책 / 홀드아웃 8셀·4정책**. 학습 풀의 4-fold GroupKFold는 매 폴드 21셀/7셀이다. 정제 규칙을 고정하고 결측 대치·표준화·변수/파라미터 선택은 학습 범위에서만 실시한다. 홀드아웃 결과를 본 뒤 재튜닝하지 않는다.

CV는 모델 선택에도 사용하므로 그 점수에는 선택 낙관편향이 남는다. 과제 EDA에서 B1 전체와 B2·B3 레이블도 이미 보았으므로 홀드아웃 분할이 분석의 독립성까지 복원하지는 않는다. **B2는 설계 이후 외부 진단이지 완전한 블라인드 테스트가 아니다.** 새 조건에서의 독립 성능 확인에는 후속 미사용 셀이 필요하다.

| DAY 2 보고 항목 | 계획 |
|---|---|
| Train (B1 CV) | 검증 폴드 MAPE 평균 + 폴드별 값 |
| Valid (B1 Hold-out) | 8셀 MAPE·MAE·오차 방향 |
| Test (B2) | 39셀 전체, standard 30/newstructure 9, B1 수명 범위 밖 구간 |
| Gap (Train-Valid) | Valid - CV |
| Gap (Valid-Test) | Test - Valid |
| Gap (Target-Test) | Test - 9.1 |

양수가 오차 증가를 뜻하도록 **표의 Gap 값은 뒤 항목-앞 항목, 단위는 퍼센트포인트**로 적는다. 평균 상대 오차와 과대 예측률도 보고한다. 원논문은 2017-06-30 연속 기록 연결, 품질 제외, B1·B2 혼합 분할을 사용하므로 과제 지정 파일과 분할의 9.1% 직접 재현이 아니다.

**ESS 활용:** 100사이클에 점검 우선순위를 제안하는 단계로 한정한다. B1에 없는 newstructure, 새 정책, 학습 입력 범위 이탈에는 추가 확인 표지를 붙인다. 과대 예측은 점검 지연 위험과 연결될 수 있으나 비용 절감률을 수치로 주장하지 않는다. 현장 배포 전에는 실제 제조·온도·부하 조건과 정확한 종료 레이블을 가진 후속 검증이 필요하다.
